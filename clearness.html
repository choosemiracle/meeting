澄心会：不替你决定

用开放问题、静默和保密，帮助一个人把自己的处境与选择慢慢理清。群体提供的不是答案，而是条件。

01 · CLEARNESS

澄心会不是“大家帮你出主意”

Clearness Committee 的独特之处，在于它把一个人的重要问题放进一个被保护的群体空间。成员的任务不是诊断、鼓励、说服或给建议，而是通过开放问题、静默、耐心与保密，帮助 focal person 更清楚地听见自己的处境与引领。

本站沿用“澄心会”这一中文名称，以避免“委员会”过于行政化。

02 · STRUCTURE

一场澄心会的核心结构

带着真实问题进入

不是“帮我证明已经决定的答案”，而是仍存在真实未知。

圆圈承诺保密

让焦点人不用为之后的社交后果自我审查。

只问真问题

问题不是建议换一个问号。

允许大量静默

问题问完后，不急着补充解释。

焦点人拥有自己的辨识

群体不替他决定。

结束后让经验继续发酵

清晰未必在两小时内完成。

03 · QUESTION LAB

互动：这是开放问题，还是伪装建议？

“你有没有想过，其实你应该先休息一段时间？”
先判断，再看为什么。
04 · REWRITE

怎样把“建议”改写成真正的问题？

建议式

“你为什么不先辞职再说？”

→ 当你分别想象“留下”和“离开”时，身体和情绪有什么不同？
建议式

“是不是因为你太在意父母看法？”

→ 在这件事上，哪些声音最容易盖过你自己的声音？
建议式

“你不是一直想做更有意义的事吗？”

→ 对你来说，“有意义”具体意味着什么？它现在怎样在你的生活里出现？
05 · TEMPLATE

一个 120 分钟的实践模板

0–10静默、保密约定、说明角色
10–25焦点人陈述问题与背景；其他人只听
25–95开放问题 + 充分停顿；必要时重新回到静默
95–105较长静默，让焦点人自行整理
105–115焦点人可以说“我现在知道了什么 / 仍不知道什么”
115–120静默结束；不做集体总结

具体时长可调整。Loring 提醒，过度结构化会把 discernment 变成机械清单。

边界

澄心会不是心理治疗，也不是危机干预。涉及严重心理危机、安全风险、创伤处理或需要专业诊断时，应寻求合适专业支持。

06 · QUERIES

Queries

QUERY 01

我提出的问题，是真的不知道答案，还是其实想把自己的答案放进对方嘴里？

QUERY 02

当焦点人沉默很久时，我能不能不急着“帮忙”？

QUERY 03

我是否相信一个人可能需要的不是更多观点，而是一个不被替他决定的空间？
